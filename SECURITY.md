# Security Policy

## Supported versions

Only the latest published release receives security fixes during the preview phase.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private security-advisory flow for this repository. Do not publish sensitive details in a public issue.

Include the affected version, Windows version, NVIDIA driver version, reproduction conditions, and whether the problem can cause an unintended power-limit write, privilege-boundary issue, or unsafe restore.

Never include private keys, signing certificates, access tokens, or unredacted machine/user identifiers.
